The Media Library stores all your files in one place. Upload a photo, video, audio file, or document once, then use it anywhere in WhatsMark.io without uploading it again.

## Uploading files

Click Upload, then drag and drop your files or choose them from your computer.

You can upload up to **10 files at a time**, with a maximum size of **16 MB per file**. You can upload images, videos, audio files, and documents. Some file types, such as SVG and program files, are not supported.

## Organizing with folders

Use folders to organize your files.

Click **New Folder** to create a folder. You can also create folders inside other folders. Move files into a folder one by one, or select multiple files and move them together.

<Warning>
Deleting a folder deletes every file inside it. Move out anything you want to keep first.
</Warning>

## Finding a file

Search by name, or use the **type** filter to show only images, PDFs, video or audio. Switch between a grid and a list view, whichever you prefer. Files are shown newest first.

<BrowserFrame
  src="/media/img/library-list.png"
  alt="The upload dialog with a drop area for files"
  caption="Image shows the media library in list."
/>

## File details and actions

Click a file to open its details on the right. You see its name, type, size, when it was uploaded, and which folder it is in. From here you can:

- **Copy URL** — copy a link to the file.
- **Open file** — open it in a new tab.
- Move it to a folder.
- Delete it.

## Use the same file again

Wherever you need to attach a file in WhatsMark.io, the Media Library opens with two tabs:

- **My Library** — pick a file you have already uploaded.
- **Upload New** — add a new one.

## Storage space

Your plan includes a storage limit. The Media Library shows how much storage you have used, and you can also see it on the Dashboard.
