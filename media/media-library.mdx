The Media Library is where your workspace's files live. Upload a photo, video, audio clip or document once, and you can reuse it anywhere WhatsMark asks for a file — instead of uploading the same thing again every time.

## Uploading files

Click **Upload**, then drag your files in or browse for them. Each file shows its own progress as it goes up.

You can send up to **10 files at a time**, each up to **16 MB**. Images, video, audio and documents are all accepted. For safety, image formats like SVG and program files are not allowed.

## Organizing with folders

Use folders to keep things tidy.

- Click **New Folder** to make one, and folders can sit inside other folders.
- Move a file into a folder from its details, or select several files and move them together.

<Warning>
Deleting a folder deletes every file inside it. Move out anything you want to keep first.
</Warning>

## Finding a file

Search by name, or use the **type** filter to show only images, PDFs, video or audio. Switch between a grid and a list view, whichever you prefer. Files are shown newest first.

## File details and actions

Click a file to open its details on the right. You see its name, type, size, when it was uploaded, and which folder it is in. From here you can:

- **Copy URL** — copy a link to the file.
- **Open file** — open it in a new tab.
- Move it to a folder.
- Delete it.

## Deleting files

<Warning>
There is no "in use" check. If you delete a file that a template, campaign or flow still uses, it will break there with no warning. Reusing a file is free, so only delete files that nothing needs anymore.
</Warning>

## Reusing a file elsewhere

Anywhere you attach a file — the [chat](/messaging/live-chat) composer, [templates](/messaging/whatsapp-templates), campaigns, flows, your profile photo, and more — a **Media Library** window opens with two tabs:

- **My Library** — pick a file you have already uploaded.
- **Upload New** — add a new one.

Picking a file you already have means you do not upload it again, and it does not use any extra storage.

## Storage space

Your plan gives you a set amount of storage, measured in MB. The bar in the Media Library shows how much you have used, and it also appears on your [Dashboard](/reporting/dashboard-and-usage).

<BrowserFrame
  src="/media/img/storage-use.png"

Everything you store counts towards this: your library files, files shared in chat, profile photos, and received media if you have turned on saving it. When you run out, uploads stop until you delete some files, add more storage, or upgrade your plan.
