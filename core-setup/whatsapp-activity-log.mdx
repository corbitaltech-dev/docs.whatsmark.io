This log lists every message WaMatrix.io sends for you. It includes messages from [campaigns](/messaging/campaigns), [automations](/automation/overview) and [Reply Bots](/automation/reply-bots), and the replies your team sends from **[Chat](/messaging/live-chat)**. Use it to check what was sent and to see why a message failed.

Each platform has its own log. In the menu, open **WhatsApp → Activity Log**, **Messenger → Activity Log** or **Instagram → Activity Log**. The page is called **WhatsApp Activity Log**, **Messenger Activity Log** or **Instagram Activity Log**. You see a platform's log only if you can use that platform.

<Note>
This is not the same as the workspace [Activity Log](/reporting/activity-logs). That page shows what people did in your workspace. This page shows only messages.
</Note>

## The list of messages

<Figure
  src="/core-setup/img/whatsapp-activity-log.png"
  alt="The WhatsApp Activity Log with All, Success and Errors tabs and a table of sent messages showing category, name, template, status, error, relation type and created date"
  caption="Image shows the WhatsApp Activity Log."
/>

Use the **All**, **Success** and **Errors** tabs to choose which messages you see. Click **Filters** to show one **Category**, or to pick a **Response**: **Success (200)** or **Errors**.

| Column | What it shows |
| --- | --- |
| **Category** | What sent the message. See [Categories](#categories) below. |
| **Name** | The campaign, automation, Reply Bot, team member or contact. It depends on the category. |
| **Template Name** | The template used, if there was one. |
| **Status** | The latest status of the message. |
| **Error** | Why the message failed, if it failed. |
| **Relation Type** | The type of contact who got the message: **Guest**, **Lead** or **Customer**. |
| **Created** | When the message was sent. |

## Categories

| Category | Where the message came from | The Name column shows |
| --- | --- | --- |
| **Campaign** | A campaign. | The campaign name. |
| **Bot Flow** | An automation (a chatbot flow). | The flow name. |
| **Inbox Reply** | A reply a team member sent from **Chat**. | The team member who replied. |
| **Initiate Chat** | A template you sent to one contact to start a chat. WhatsApp and Messenger only. On Messenger, this works only if the person messaged your Page in the last 7 days. | The contact. |
| **Reply Bot** | A Reply Bot that answered a comment, a mention or a story reply. Messenger and Instagram only. | The Reply Bot name. |
| **Message Bot** | Any other automatic message, such as the answer to an ice breaker or a message that confirms someone opted in or out. | Nothing. |

## Message statuses

| Status | What it means |
| --- | --- |
| **pending** or **queued** | The message is waiting to be sent. |
| **accepted** | Meta has accepted the message. |
| **sent** | The message has been sent. |
| **delivered** | The message reached the contact. |
| **read** | The contact opened the message. |
| **replied** | The contact replied to a campaign message. It has the same colour as **read**. |
| **failed** | The message was not sent. Check the **Error** column to see why. |

## View message details

Open the three-dot menu (⋮) at the end of a row and choose **View**.

<Figure
  src="/core-setup/img/whatsapp-activity-log-view.png"
  alt="The message details panel with Response and Raw Content tabs, showing the status, response code, response time, wamid, and the reply data returned by WhatsApp"
  caption="Image shows the message details with the Response tab open."
/>

- **Response** shows the status, the response code, the response time and the message ID. On WhatsApp the message ID is called **wamid**. On Messenger and Instagram it is called **Message ID**. Below that, you see the data Meta sent back.
- **Raw Content** shows what WaMatrix.io sent to Meta. It includes the message type and the account it was sent from. This is the **Phone number ID** on WhatsApp, the **Page ID** on Messenger and the **Account ID** on Instagram. WhatsApp messages also show the **Business acct ID**.

## How long entries stay

- Entries stay for 90 days. After that, WaMatrix.io deletes them automatically.
- If you delete a campaign, an automation or a Reply Bot, its messages are also removed from this log.
- You can delete entries yourself. Choose **Delete** from a row's menu, or tick several rows and click **Delete**. To remove every entry for that platform, click **Clear Logs**. Deleting needs the **Delete** permission for **Message Activity Log**.
