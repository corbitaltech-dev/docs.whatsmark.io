The **Basic** category includes the flow steps you'll use most often to send messages to your customers.

## Which steps work on which platform

Each flow runs on one platform: WhatsApp, Messenger or Instagram. Some steps work only on some platforms. The Flow Builder hides the steps that your flow's platform can't send.

| Step | WhatsApp | Messenger | Instagram |
|---|---|---|---|
| Text Message | Yes | Yes | Yes |
| Button Message | Yes | Yes | Yes |
| Call To Action | Yes | No | Yes |
| WhatsApp Template | Yes | No | No |
| WhatsApp Flow | Yes | No | No |
| Send Template | No | Yes | Yes |

Sometimes a step is already on the canvas, but the flow's platform can't send it. Then the step shows a message, for example:

> WhatsApp Flow is not supported on Instagram and will not be sent. Remove this node.

The **Save** button stays off until you remove that step.

## Text Message

**What it does.** Sends a plain text reply — no buttons, no image. The simplest way to say something.

**When to use it.** Greetings, confirmations, opening hours, an address, a thank-you at the end of a flow.

**How to set it up.** Click the card and type your message in the **Message Text** box. Type **@** anywhere to insert a [merge field](/messaging/merge-fields).

The **Message Text** field is required. The limit depends on the platform:

- **WhatsApp:** up to **4,096 characters**.
- **Messenger:** up to **2,000 characters**.
- **Instagram:** up to **1,000 bytes**. A byte is a unit of size. A plain English letter or number counts as 1 byte. An emoji counts as 4 bytes, and a letter in some languages, such as Hindi, counts as 3. So a message with emojis fits fewer characters.

A counter below the field shows how much you've used. On Instagram it counts bytes. If your text is too long, you see: "Instagram messages can be at most 1000 bytes (an emoji counts as 4)."

These limits come from Meta, not from WaMatrix.io. See Meta's [Instagram messaging documentation](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/messaging-api).

![Text Message settings on a WhatsApp flow, with a Message Text box containing a greeting that uses the contact first name merge field and a character counter reading 118 of 4096](/automation/img/basic/text-message-settings-whatsapp.png)


**Example**

> Hi {'{{contact.first_name}}'}, thanks for reaching out to Sunrise Cafe! We're open 8am to 10pm every day. How can we help?

![A Start Trigger set to exact match on the keyword menu, connected to a Text Message step containing a greeting that uses the contact first name merge field](/automation/img/basic/text-message.png)

## Button Message

**What it does.** Sends a message with up to three clickable buttons. The customer chooses an option by clicking a button, and the chatbot continues with the next flow step for that option.

**When to use it.** Use button messages when you want customers to choose from a list of options instead of typing a reply. They're ideal for main menus, yes/no questions, or letting customers select a service.

**How to set it up.**

1. Type the message in the **Message** box.
2. Under **Buttons**, add each button and fill in its **Button Text** — for example, `Yes, continue`.
3. **Value (payload)** is optional; leave it blank and it defaults to the button text.
4. Back in the Flow Builder, each button has its own connection point on the right. You must connect each button to the flow step you want the chatbot to run when that button is selected.

The **Message Text** field is required and supports up to **1,024 characters**. You can add up to **3 buttons**, and each Button Text is required and limited to **20 characters**.

**On Instagram.** Your buttons show under the message, as on WhatsApp. If the message text is longer than 640 characters, Instagram can't show them as buttons. They are sent as quick replies instead. Quick replies are small tap options that disappear after the customer taps one. This is an Instagram rule. See Meta's [button template](https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/messaging-api/button-template) documentation.

![Button Message settings with a Message Text box, a Buttons counter reading 3 of 3, and three buttons each with its Button Text and Value payload filled in](/automation/img/basic/button-message-settings.png)

**Example**

> **Message:** What would you like to do today?
> **Buttons:** `Book a table` · `See the menu` · `Talk to us`

Connect `Book a table` to an [**Ask Question**](/automation/flow-steps/ask#ask-question) asking for the date, `See the menu` to a [**Media Message**](/automation/flow-steps/interactive#media-message) with your PDF menu, and `Talk to us` to a [**Text Message**](#text-message) saying someone will reply shortly.

![A Button Message with the buttons Book a table, See the menu, and Talk to us, each connected to a different next step — an Ask Question, a Media Message, and a Text Message](/automation/img/basic/button-message.png)

## Call To Action

**What it does.** Sends a message with a button that opens a website or web page. When the customer clicks the button, they're taken directly to the link you've provided.

**When to use it.** Sending someone to a product page, a payment link, a booking page, or a form.

**How to set it up.** Enter the **Body Text**, the **Button Text** (for example, `Learn More`), and the **Button Link** you want the button to open. You can also add an optional **Header** and **Footer**.

The Body Text, Button Text, and Button Link fields are all required. The Body Text supports up to **1,024 characters**, Button Text up to **20 characters**, and the optional Header and Footer up to **60 characters** each.

**On Instagram.** This step works on WhatsApp and Instagram flows. It is hidden on Messenger flows. Instagram has no header or footer, so only the **Body Text** and the button are sent. Instagram also shows at most 640 characters of text above a button, so keep the Body Text short. Longer text is cut off.

![Call To Action settings with a Summer Sale header, a Body Text box, a Button Text of Shop now, a Button Link, a footer, and the Show typing indicator switch turned on](/automation/img/basic/call-to-action-settings.png)

**Example**

> **Header:** Summer Sale
> **Body Text:** Everything in store is 20% off until Sunday. Tap below to browse.
> **Button Text:** Shop now
> **Button Link:** `https://example.com/sale`
> **Footer:** Free delivery over ₹999

![A Start Trigger set to exact match on the keyword sale, connected to a Call To Action step showing the Summer Sale message with a Shop now button](/automation/img/basic/call-to-action.png)

## WhatsApp Template

**What it does.** Sends one of your approved [WhatsApp templates](/messaging/whatsapp-templates).

**When to use it.** Use this step to send a ready-made, approved message from your flow — such as an order confirmation, a delivery update, or an appointment reminder.

**How to set it up.** Click the step and select your template. If it has [variables](/getting-started/concepts#the-building-blocks), fill in each **Body variable** field — type **@** to insert a [merge field](/messaging/merge-fields) like the contact's name. If the template has a media header, upload the image, video, or document here too.

Some templates have a link button whose web address ends in a variable. For example, a **Track order** button that opens a page for each order. For each button like this, you see a field called **Button "Track order" URL parameter**, with your button's own text in the name. Fill it in with the part that changes, such as the order number. You can type **@** here too.

You must select a template before the flow can be saved. Length limits come from the template itself, which Meta has already approved.

![WhatsApp Template settings with the order_shipped marketing template selected and two body variable fields filled with the contact first name and order number merge fields](/automation/img/basic/whatsapp-template-settings.png)

**Example**

A Shopify-triggered flow starts with the `order_shipped` template:

> Hi {'{{1}}'}, your order {'{{2}}'} has shipped and should arrive in 2–3 days.

Map `{'{{1}}'}` to the contact's first name and `{'{{2}}'}` to the order number.

![A Start Trigger set to the Shopify Order shipped event, connected to a WhatsApp Template step previewing the shipping confirmation message with the contact first name and order number merge fields](/automation/img/basic/whatsapp-template.png)

<Note>
You need at least one approved template first. See [WhatsApp Templates](/messaging/whatsapp-templates). This step works only on WhatsApp flows. It is hidden on Messenger and Instagram flows.
</Note>

## WhatsApp Flow

**What it does.** Sends one of your [WhatsApp Flows](/appointment-and-flow/whatsapp-flows) as part of the conversation — the customer clicks a button to open the form right inside WhatsApp.

**When to use it.** Use this to collect structured answers, or let someone book an appointment, from within an automated conversation — for example, after a Button Message option like "Book an appointment."

**How to set it up.** Select the **WhatsApp Flow** to send. You can also add optional **Body Text** and change the **Button Text** shown on the message (defaults to "Open").

Only **Published** flows on the same WhatsApp account as this automation appear in the dropdown. Selecting a flow is required — the flow can't be saved without one.

![WhatsApp Flow settings with a flow selected from the dropdown, optional body text, and a Button Text field showing Open](/automation/img/basic/whatsapp-flow-settings.png)

<Note>
This step needs an open 24-hour conversation window with the customer. It works only on WhatsApp flows. It is hidden on Messenger and Instagram flows.
</Note>

## Send Template

**What it does.** Sends one of your saved templates. On a Messenger flow, you choose from your [Messenger templates](/messaging/messenger-templates). On an Instagram flow, you choose from your [Instagram templates](/messaging/instagram-templates). This step was called **Messenger Template** before.

**When to use it.** Use this step to send a ready-made message from a Messenger or Instagram flow — such as a welcome message or a quick reply menu.

**How to set it up.** Select your template. You only see templates for the Page or Instagram account that this flow uses. If it has [variables](/getting-started/concepts#the-building-blocks), fill in each **Body variable** field — type **@** to insert a [merge field](/messaging/merge-fields) like the contact's name. A **Preview** below shows how the message will look, including any buttons.

You must select a template before the flow can be saved.

![Template step settings on a Messenger flow, with the welcome_message button template selected, one body variable set to the contact first name merge field, and a preview showing the greeting with Know More and Click Here buttons](/automation/img/basic/messenger-template-settings.png)

**Example**

A flow triggered by the keywords `hi` or `hello` starts with a `welcome_message` template:

> Hi {'{{1}}'}, welcome to our store! How can we help you today?

Map `{'{{1}}'}` to the contact's first name. The template's **Know More** and **Click Here** buttons are shown in the preview.

![A Start Trigger set to exact match on the keywords hi and hello, connected to a template step on a Messenger flow, previewing a greeting with Know More and Click Here buttons](/automation/img/basic/messenger-template.png)

<Note>
This step works only on Messenger and Instagram flows. It is hidden on WhatsApp flows. To send a template on WhatsApp, use the [WhatsApp Template](#whatsapp-template) step. See [Messenger Templates](/messaging/messenger-templates) and [Instagram Templates](/messaging/instagram-templates).
</Note>

## Show Typing Indicator

Turn this on to show a **"typing..."** bubble for a moment before your message arrives, so the chat feels more natural. It's available on every step in this category except **Send Template**.

It works on WhatsApp and Messenger flows. Instagram flows don't send a typing bubble, so the switch doesn't show there.


![The Show typing indicator switch turned on, with helper text explaining it briefly shows the WhatsApp typing bubble before the message sends and requires an inbound trigger](/automation/img/basic/show-typing-indicator.png)

<Note>
This is a paid feature. The **Show Typing Indicator** option isn't available on the Free Forever plan. See [Free vs. Paid Plans](/getting-started/free-vs-paid).
</Note>

## A worked example

A small clinic wants a flow that greets new patients and routes them:

1. [**Start Trigger**](/automation/flow-builder#the-start-trigger) — First message from lead/customer.
2. [**Text Message**](#text-message) — "Hi {'{{contact.first_name}}'}, welcome to Green Valley Clinic."
3. [**Button Message**](#button-message) — "How can we help?" with `Book an appointment`, `Opening hours`, `Speak to reception`.
4. From `Opening hours`, a **Text Message** with the timings.
5. From `Speak to reception`, a **Text Message** saying a team member will reply.
6. From `Book an appointment`, continue into the [Ask](/automation/flow-steps/ask) steps to collect the details.

![The finished clinic flow — a Start Trigger on first message leading to a welcome Text Message, then a Button Message with Book an appointment, Opening hours, and Speak to reception, each connected to an Ask Question or a Text Message](/automation/img/basic/worked-example-clinic-flow.png)
