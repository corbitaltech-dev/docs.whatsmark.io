The **interactive** category flow steps let you send more than plain text. Share lists, images, videos, audio, documents, locations, contact cards, and emoji reactions to make conversations easier and more engaging.

![Flow Builder with the Interactive tab selected, showing the List Message, Media Message, Location, Contact Card, and Reaction tiles, and a flow connecting a Start Trigger to a List Message whose options lead to a Media Message, a Location, and a Contact Card](/automation/img/interactive/interactive-flow-steps.png)

## List Message

**What it does.** Sends a message with a button that opens a list of options. Each option can lead to a different step in your flow.

**When to use it.** Use a **List Message** when you want customers to choose from several options. It's a better choice than **Button Messages** when you have more than three options.

**How to set it up.**

1. Fill in the **Body Text**, and optionally a **Header** and **Footer**.
2. Set the **Button Text** — the words on the button that opens the menu, such as `View options`.
3. Create one or more sections and add your list items. Then connect each item to the next step in your flow.

- **Body Text** is required, and supports up to 1,024 characters.
- **Button Text** is required, and supports up to 20 characters.
- **Header** and **Footer** are optional, up to 60 characters each.
- You need at least **one Section**, with a title and at least **one item**.
- You can add up to 10 sections, but no more than **10 items in total** across all of them.
- Section and item titles are limited to 24 characters, and item descriptions to 72 characters.

Most of these limits come from WhatsApp, not from WaMatrix.io. See Meta's [Interactive list messages](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/interactive-list-messages) documentation.

![List Message settings with Header, Body Text, Footer, and Button Text fields, and a Sections area containing a section with two items, plus Add Item and Add Section buttons](/automation/img/interactive/list-message-settings.png)

**Example**

A salon lists its services:

> **Body Text:** Which service would you like to book?
> **Button Text:** View services
> **Section — Hair:** Haircut · Colour · Blow dry
> **Section — Nails:** Manicure · Pedicure · Gel extensions

Each item leads to an **Ask Question** asking for a preferred date.

![A Start Trigger connected to a List Message step previewing a Book an Appointment menu with a View Services button and a Hair Services section listing Haircut and Hair Colour](/automation/img/interactive/list-message.png)

<Note>
List Message is a WhatsApp-only step. It's hidden on Messenger flows.
</Note>

## Media Message

**What it does.** Sends an image, video, audio file, document, or sticker. You can also add an optional caption.

**When to use it.** Use it to share product photos, brochures, price lists, menus, user guides, or videos with your customers.

**How to set it up.** Choose the media type, upload a file or select one from the [Media Library](/media/media-library), and add a **Caption** if needed. For documents, you can set the **Filename** the customer sees.

- A **file** is required — upload one, or pick one from the Media Library, before the flow can be saved.
- **Caption** is optional, and supports up to 1,024 characters.
- **Filename** applies to documents only, and is optional. Leave it blank and the customer sees the name of the file you uploaded.
- **Image** — JPG or PNG, up to 5 MB.
- **Video** — MP4 or 3GP, up to 16 MB.
- **Audio** — AAC, MP3, MP4, AMR, or OGG, up to 16 MB.
- **Document** — PDF, Word, Excel, PowerPoint, or plain text, up to 100 MB.
- **Sticker** — WebP, up to 100 KB still or 500 KB animated.

These file types and size limits come from WhatsApp, not from WaMatrix.io. See Meta's [Media](https://developers.facebook.com/documentation/business-messaging/whatsapp/business-phone-numbers/media) documentation.

![Media Message settings with a Media Type set to Image, an uploaded file named sale.png showing a New Arrivals catalog preview, and a Caption field describing the product catalog](/automation/img/interactive/media-message-settings.png)

**Example**

> **Type:** Image
> **File:** sale.png
> **Caption:** 🛍️ Here's our latest product catalog. Browse our collection and let us know if you'd like more information about any item.

![A flow connecting a Start Trigger to a List Message and then a Media Message previewing a New Arrivals product catalog image with a caption](/automation/img/interactive/media-message.png)

<Tip>
Give documents a clear file name. `Menu-2026.pdf` looks far more trustworthy than `file_8823.pdf`.
</Tip>

## Location

**What it does.** Sends a location that customers can open for directions.

**When to use it.** Use it to share your shop, office, clinic, restaurant, pickup point, or anywhere else a customer needs to find you.

**How to set it up.** Use **Search Location** to find a place, drop a pin on the **Map**, or type the **Coordinates** in manually. Then enter the **Location Name** and **Address**.

- **Coordinates** are required — a latitude between -90 and 90, and a longitude between -180 and 180. Searching for a location or dropping a pin fills them in automatically.
- **Location Name** supports up to 100 characters.
- **Address** supports up to 200 characters.

![Location settings with a search box, a map showing a dropped pin, latitude and longitude fields, and Location Name and Address fields filled in for Sunrise Cafe](/automation/img/interactive/location-settings.png)

**Example**

> **Location Name:** Sunrise Cafe
> **Address:** 12 Park Road, Mumbai 400001

![A flow connecting a Start Trigger to a List Message and then a Location step previewing a map pin for the business store with its name and address](/automation/img/interactive/location.png)

## Contact Card

**What it does.** Sends a contact card that customers can save to their phone.

**When to use it.** Use it to share a salesperson's contact, your support number, or another business contact.

**How to set it up.** Enter the contact's **First Name**, **Last Name**, and **Phone**. You can also add an **Email**, **Company**, and **Title**.

- **First Name**, **Last Name**, and **Phone** are all required.
- **Email**, **Company**, and **Title** are optional.
- **First Name**, **Last Name**, **Company**, and **Title** each support up to 100 characters.
- **Email** supports up to 320 characters.
- You can send up to 20 contact cards in one step.

![Contact Card settings with First Name, Last Name, Phone, Email, Company, and Title fields filled in for a StyleHub Support contact, and an Add Another Contact button](/automation/img/interactive/contact-card-settings.png)

**Example**

> StyleHub Support · Customer Support · StyleHub · support@stylehub.com

![A flow connecting a Start Trigger to a List Message and then a Contact Card step previewing a StyleHub Support contact with Message and Save contact buttons](/automation/img/interactive/contact-card.png)

<Note>
Contact Card is a WhatsApp-only step. It's hidden on Messenger flows.
</Note>

## Reaction

**What it does.** Adds an emoji reaction to a customer's message instead of sending a new message.

**When to use it.** Use it to quickly acknowledge a customer's message without sending a reply.

**How to set it up.** Pick an emoji from the list. The reaction is automatically added to the customer's most recent message.

- An **emoji** is required. Pick one from the list shown — you can't type your own.
- **Message ID** is required. It comes pre-filled with `{{last_message_id}}`, which reacts to the customer's latest message — leave it as is, or replace it with a different [merge field](/messaging/merge-fields) to react to a specific message.

![Reaction settings with a grid of emoji to choose from and a Message ID field noting that leaving it blank reacts to the latest inbound message](/automation/img/interactive/reaction-settings.png)

**Example**

After the customer taps `Confirm booking`, add a Reaction with 👍 so they can see it registered straight away, then send the confirmation text.

<Note>
Reaction is a WhatsApp-only step. It's hidden on Messenger flows.
</Note>

## A worked example

A furniture shop answers a product enquiry:

1. **Start Trigger** — When message contains `sofa`, `couch`.
2. **List Message** — "Which style are you after?" with sections for Fabric, Leather and Recliner.
3. From each item, a **Media Message** with photos of that range.
4. A **Button Message** — `Visit the showroom` / `Talk to sales`.
5. From `Visit the showroom`, a **Location** with the shop address.
6. From `Talk to sales`, a **Contact Card** for the sales manager.

![The finished clinic flow — a Start Trigger on first message leading to a welcome Text Message, then a Button Message with Book an appointment, Opening hours, and Speak to reception, each connected to an Ask Question or a Text Message](/automation/img/interactive/worked-example-furniture.png)


## Show Typing Indicator

**Show Typing Indicator** — Available on every flow step in this category except **Reaction**. When enabled, the customer sees a "typing..." indicator before the message is sent, making the conversation feel more natural.


![The Show typing indicator switch turned on, with helper text explaining it briefly shows the WhatsApp typing bubble before the message sends and requires an inbound trigger](/automation/img/basic/show-typing-indicator.png)

<Note>
This is a paid feature. The **Show Typing Indicator** option isn't available on the Free Forever plan.
</Note>
