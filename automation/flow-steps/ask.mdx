**Ask** category flow steps let you collect information from **customers**, such as their **name**, **phone number**, **email address**, **location**, or **files**. Each step asks a question, validates the response, and saves the answer to the contact record for later use.

![Flow Builder with the Ask tab selected, showing the Ask Question, Ask Phone, Ask Email, Ask Address, Ask Location, Ask Media, and Get Input tiles, and a job application flow connecting a Start Trigger to an Ask Question, an Ask Phone, an Ask Media, and a closing Text Message](/automation/img/ask/ask-flow-steps.png)

## How every Ask step works

<Steps>
<Step title="Write the question">
Enter your question in the Question field. Depending on the step, this field may be called Question, Question Message, or Media Question. Type **@** to insert a [merge field](/messaging/merge-fields), such as the contact's first name.
  
</Step>

<Step title="Choose where to save the answer">
  Set the **Capture Attribute** field. This is where the customer's answer will be saved. Give it a meaningful name, such as `preferred_date`. You can save the answer to a [custom fields](/core-setup/custom-fields), or to a flow variable that's only available during the current conversation.
</Step>

<Step title="Set the retries">
  **Number of Attempts** determines how many times the chatbot asks the question again if the customer's answer isn't valid. Set it to `0` to accept the first answer without asking again.
</Step>

<Step title="Write the retry messages">
  **Validation Error Message** is shown when the customer's answer isn't valid. You can use the default message or write your own. The same question is then asked again.
</Step>
</Steps>

In later message steps, type **@** in any message field to insert the saved answer as a [merge field](/messaging/merge-fields).

<Note>
**Ask Address** and **Ask Location** don't have the retry fields — they save whatever the customer sends.
</Note>

## Ask Question

**What it does.** Asks for anything and checks the answer against a format you choose: **Text**, **Any**, **Number**, **Email**, **Phone**, **URL**, **Date**, or a **Regular expression** pattern.

**When to use it.** Use it to collect any text information, such as a customer's name, order number, party size, preferred date, or review.

**Required fields**

- **Question** and **Capture Attribute** are required.
- **Attribute Format** sets what a valid answer looks like. It defaults to **Any**, which accepts whatever customer send.
- **Pattern** is required, but only if you set the Attribute Format to **Regular expression**.

![Ask Question settings with a Question box, a Capture Attribute of booking_date, an Attribute Format of Date, Number of Attempts set to 2, a Validation Error Message, and an Attempts Over Message](/automation/img/ask/ask-question-settings.png)

**Example**

> **Question:** What date would you like to book?
> **Attribute Format:** Date
> **Capture Attribute:** `booking_date`
> **Number of Attempts:** 2
> **Validation Error Message:** That doesn't look like a date. Please send it as DD/MM/YYYY.

![A Start Trigger set to exact match on the keywords Book and Schedule, connected to an Ask Question step asking what date the customer would like to book](/automation/img/ask/ask-question.png)

## Ask Phone

**What it does.** Asks the customer for a phone number and checks that it's valid.

**When to use it.** Use it when you need to collect a phone number, such as for a callback or an alternate contact number.

**Required fields**

- **Question** and **Capture Attribute** are required. The format is already set to Phone for you.

![Ask Phone settings with a Question box reading Please send your phone number, helper text saying it validates as a phone number, a Capture Attribute of callback_number, and the Show typing indicator switch turned off](/automation/img/ask/ask-phone-settings.png)

**Example**

> **Question:** Please send your phone number
> **Capture Attribute:** `callback_number`

![A Start Trigger set to exact match on the keywords Book and Schedule, connected to an Ask Phone step asking the customer to send their phone number](/automation/img/ask/ask-phone.png)

## Ask Address

**What it does.** Asks the customer for their address.

**When to use it.** Use it to collect a delivery address, service address, or any other location where you need to visit or deliver.

**Required fields**

- **Question Message** and **Capture Attribute** are required.
- **Formatted Response Attribute** is optional. Use it if you want to save the formatted address in a separate field.
- There are no validation or retry options for this step. The customer's response is saved as it is.

![Ask Address settings with a Question Message box asking for the full delivery address including the pincode, a Capture Attribute of delivery_address, an empty Formatted Response Attribute, and the Show typing indicator switch turned off](/automation/img/ask/ask-address-settings.png)

**Example**

> **Question Message:** What's the full delivery address, including the pincode?
> **Capture Attribute:** `delivery_address`

![A Start Trigger set to a WooCommerce order event, connected to an Ask Address step asking for the full delivery address including the pincode](/automation/img/ask/ask-address.png)

## Ask Location

**What it does.** Asks the customer to share their actual GPS location using WhatsApp's location button.

**When to use it.** Use it when you need the customer's exact location, such as for deliveries, pickups, or on-site services.

**Required fields**

- **Question Message** and **Capture Attribute** are required.
- There are no validation or retry options for this step. The customer’s response is saved as it is.

![Ask Location settings with a note explaining that WhatsApp shows a Send location button the contact taps to share their GPS location, a Question Message box, a Capture Attribute of pickup_location, and helper text saying the answer is stored as lat, lng](/automation/img/ask/ask-location-settings.png)

**Example**

> **Question Message:** Please share your location so the driver can find you.
> **Capture Attribute:** `pickup_location`

![A Start Trigger set to exact match on the keyword location, connected to an Ask Location step asking the customer to share their location so the driver can find them](/automation/img/ask/ask-location.png)

<Note>
Ask Location is a WhatsApp-only step. It's hidden on Messenger flows.
</Note>

## Ask Media

**What it does.** Asks the customer to upload a file. You can choose which file types are allowed, such as  **Image**, **Video**, **Audio**, **Document** or **Sticker** or **Any file**,.

**When to use it.** Use it when you need customers to send files, **such as photos of damaged items**, **ID documents**, **prescriptions**, **screenshots**, or other **supporting documents**.

**Required fields**

- **Media Question** and **Capture Attribute** are required.
- **Media Type** defaults to **Any**, which accepts any file the customer sends.

![Ask Media settings with a Media Question box asking for a photo of the damaged item, a Capture Attribute of damage_photo, a Media Type of Image, Number of Attempts set to 1, a Validation Error Message, and an Attempts Over Message](/automation/img/ask/ask-media-settings.png)

**Example**

> **Media Question:** Please send a photo of the damaged item so we can process your return.
> **Media Type:** Image
> **Capture Attribute:** `damage_photo`

![A Start Trigger set to exact match on the keywords replace and damage, connected to an Ask Media step asking for a photo of the damaged item](/automation/img/ask/ask-media.png)

## Get Input

**What it does.** Collects a customer's response and saves it. You can choose the type of answer to accept, such as **text**, **number**, **email**, **phone number**, **URL**, **date**, or **any value**.

**When to use it.** Use it when you need to collect a simple answer without additional validation or settings.

**Required fields**

- **Question** and **Capture Attribute** are required.
- **Attribute Format** defaults to **Any**, which accepts whatever they send.

![Get Input settings with a Question box asking how many people the booking is for, a Capture Attribute of party_size, an Attribute Format of Any, Number of Attempts set to 0, and the Show typing indicator switch turned off](/automation/img/ask/get-input-settings.png)

**Example**

> **Question:** How many people is the booking for?
> **Attribute Format:** Number
> **Capture Attribute:** `party_size`

![A Start Trigger set to exact match on the keyword book, connected to a Get Input step asking how many people the booking is for](/automation/img/ask/get-input.png)

## A worked example

A restaurant collects a booking:

1. **Button Message** — "How can we help?" with `Book a table`.
2. **Ask Question** (Text) — "What name should we put the booking under?" → `booking_name`
3. **Get Input** (Number) — "How many people?" → `party_size`
4. **Ask Question** (Date) — "Which date?" → `booking_date`
5. **Ask Phone** — "What number can we call if anything changes?" → `callback_number`
6. **Text Message** — "Thanks {'{{contact.first_name}}'}! We've noted a table for {'{{vars.party_size}}'} on {'{{vars.booking_date}}'} under {'{{vars.booking_name}}'}. We'll confirm shortly."

![The finished booking flow — a Start Trigger on the keyword book leading to a Button Message with a Book a table button, then an Ask Question for the booking name, a Get Input for the party size, an Ask Question for the date, an Ask Phone for the callback number, and a closing Text Message that confirms the booking using the saved answers as merge fields](/automation/img/ask/worked-example-booking-flow.png)

Add a **Google Sheets** step at the end and every booking lands in a spreadsheet automatically.

## Show Typing Indicator

**Show Typing Indicator** — Available on every flow step in this category. When enabled, the customer sees a "typing..." indicator before your question is sent, making the conversation feel more natural.

The typing indicator works on both WhatsApp and Messenger, but only when the customer has already started the conversation.

<Note>
This is a paid feature. The **Show Typing Indicator** option isn't available on the Free Forever plan.
</Note>
