The **Flow Builder** is where you create your chatbot conversation. Choose from different flow steps such as [**Text Message**](/automation/flow-steps/basic#text-message), [**Button Message**](/automation/flow-steps/basic#button-message), [**Ask Question**](/automation/flow-steps/ask#ask-question), [**Condition**](/automation/flow-steps/advanced#condition), or [**API Request**](/automation/flow-steps/advanced#api-request) then connect them to control what happens next. Every flow begins with a [**Start Trigger**](#the-start-trigger), which determines when the conversation starts. After that, each flow step runs in the order you've connected them.

Think of it like drawing a conversation on paper:

When someone says **"hi" → send them a welcome message. Then → show three buttons → If they tap "Book a table"**, ask for their preferred date.

## How the builder works

<Steps>
<Step title="Open the builder">
  In the main menu, open **WhatsApp → Automations**, **Messenger → Automations** or **Instagram → Automations**. Click the three-dot menu (⋮) at the end of the flow's row, then click **Flow Builder**.
</Step>

<Step title="Set the Start Trigger">
Every flow starts with a [**Start Trigger**](#the-start-trigger). Click it to choose who can start the flow and what should start it. For example, a flow can start when someone sends a keyword. It can also start from a [Shopify](#shopify) or [WooCommerce](#woocommerce) order, a [new lead](#leads) or a [Reply Bot](#flows-started-by-a-reply-bot-or-ice-breaker).
</Step>

<Step title="Add flow steps">
  Pick a category tab at the top — **Basic**, **Interactive**, **Ask**, **Advanced** or **Integrations** — then click a tile, or drag it into the builder.
</Step>

<Step title="Join them up">
Connect each flow step in the order you want the conversation to happen. The chatbot follows these connections from one step to the next.
</Step>

<Step title="Fill in each flow step">
Click a flow step card to open its settings on the right. Then fill in the details required for that step, such as the message, buttons, questions, or other options.
</Step>

<Step title="Save">
  Click **Save Flow** at the top right. If a required field is empty, that flow step turns red. You can't click **Save Flow** until you fix it.
</Step>
</Steps>

<Tip>
Type **@** in almost any text box to drop in a merge field, such as the contact's first name. See [Merge Fields](/messaging/merge-fields).
</Tip>

## The Start Trigger
Every flow begins here. The Start Trigger decides when your chatbot starts. Open the **Start Trigger** settings, then choose a **Trigger Source**:

- **Message** — someone sends you a message on the flow's platform: WhatsApp, Messenger or Instagram.
- **Shopify** — something happens to an order in your Shopify store. *(Needs a paid plan.)*
- **WooCommerce** — something happens to an order in your WooCommerce store. *(Needs a paid plan.)*
- **Leads** — a new lead arrives from Facebook Lead Ads or IndiaMART. *(Needs a paid plan.)*
- **Reply Bot** — a Reply Bot or an ice breaker starts the flow. *(Reply Bots need a paid plan.)*

Shopify, WooCommerce and Leads find the person by their phone number, so they work on WhatsApp flows only. Messenger and Instagram flows don't show them. **Reply Bot** shows on Messenger and Instagram flows only.

If an older Messenger flow still uses one of these three, the Start Trigger is marked in red and you can't save the flow. Change the **Trigger Source** to **Message** to fix it.

The rest of the card changes depending on which one you choose. The following sections explain each option.

### Message

The most common choice. The flow starts when someone messages you on the flow's platform.

![Start Trigger settings with Trigger Source set to Message, Contact Type showing Lead and Customer selected, Trigger Type set to On exact match, and a Keywords box containing the keyword menu](/automation/img/message-trigger.png)

**Contact Type** — Choose which contacts can start this flow. You can select one or more contact types, such as **Lead**, **Customer**, or **Guest**.

**Trigger Type** — Choose how an incoming message is matched. There are four options:

| Option | What it means |
| --- | --- |
| **On exact match** | The customer's message must exactly match one of your keywords. For example, if your keyword is **menu**, only **menu** will trigger the flow. Messages like "send me the menu" or "show me the menu" won't.|
| **When message contains** | The flow starts if your keyword appears anywhere in the customer's message. For example, if your keyword is **menu**, messages like **send me the menu** or **show the menu** will also trigger the flow.|
| **First message from lead/customer** | Starts the flow when a lead or customer contacts you for the first time. After that, this trigger won't run again for the same contact. |
| **No keyword matches (fallback)** | Use this as your default flow. If no other keyword triggers match, this flow runs automatically to make sure every customer receives a response. |

**Keywords** — Available only **when On Exact Match** or **When Message Contains** is selected. Enter a keyword and press Enter to add it. Add multiple keywords or common variations so customers can trigger the flow using different words.

**Example.** If you choose When Message Contains and add the keywords **book**, **table**, and **reservation**, messages like **"Can I book a table for 4?"** or **"I'd like to make a reservation"** will automatically start the booking flow.
<Tip>
We recommend creating one **First Message from Lead/Customer** flow to greet new **contacts** and one **No Keyword Matches (Fallback)** flow to handle messages that don't match any keywords. This way, every customer receives a response.
</Tip>

### Shopify

This flow runs automatically when an order changes in your connected Shopify store. Customers don't need to send a message. WaMatrix.io uses the customer's phone number to find the correct contact and start the flow.

![Start Trigger settings with Trigger Source set to Shopify and a Shopify Event dropdown set to Cart abandoned, above a note about the 24-hour messaging window](/automation/img/shopify-trigger.png)

Pick one **Shopify Event**:

| Event | Fires when |
| --- | --- |
| **Cart abandoned** | Someone adds to cart and leaves without paying. |
| **Order placed** | An order is successfully placed. |
| **COD order confirmed** | A cash-on-delivery order is confirmed. |
| **Order partially shipped** | Part of the order has shipped. |
| **Order shipped** | The order has shipped. |
| **Order out for delivery** | The courier is delivering it today. |
| **Order delivered** | The order reached the customer. |
| **Order cancelled** | The order was cancelled. |

**What it's for.** Keep customers updated throughout their order journey. Use it to recover abandoned carts, send order notifications, and reduce support questions like "Where's my order?"

**Example.** When a customer abandons their **cart**, wait **1 hour** before sending a **WhatsApp template** with a discount code to encourage them to return and complete their order.

<Note>
The Order **Out for Delivery** and **Order Delivered** triggers work only if your shipping carrier sends tracking updates to Shopify. If you mark orders as fulfilled manually, these triggers won't run.
</Note>

### WooCommerce

This flow runs automatically when an order changes in your connected WooCommerce store. Customers don't need to send a message. WaMatrix.io uses the customer's phone number to find the correct contact and start the flow.

Pick one **WooCommerce Event**:

![Start Trigger settings with Trigger Source set to WooCommerce and a WooCommerce Event dropdown set to Cart abandoned, above a note about the 24-hour messaging window](/automation/img/woocommerce-trigger.png)

| Event | Fires when |
| --- | --- |
| **Order create** | A new order is placed. |
| **Order update** | An order's status changes. |
| **Cart abandoned** | Someone leaves without completing checkout. |

Order Update runs every time an order status changes. Add a [**WooCommerce Condition**](/automation/flow-steps/integrations#woocommerce-condition) node after the trigger to choose which status changes should continue the flow. For example, you can send a message only when an order is marked as shipped or only for cash-on-delivery orders.

<Warning>
Shopify and WooCommerce flows start automatically when an event occurs in your store, not when a customer sends you a message. If the customer hasn't messaged you in the last [24 hours](/getting-started/concepts#two-whatsapp-rules-that-shape-everything), start the flow with a [**WhatsApp Template**](/automation/flow-steps/basic#whatsapp-template). This ensures the first message is delivered successfully.
</Warning>

<Note>
Shopify and WooCommerce triggers are paid features and need a connected store. See [Shopify](/settings/shopify) and [WooCommerce](/settings/woocommerce).
</Note>

### Leads

This flow runs when a new lead arrives from [Facebook Lead Ads](/settings/facebook-lead-ads) or [IndiaMART](/settings/indiamart). *(Needs a paid plan.)* WaMatrix.io uses the lead's phone number to find the contact and start the flow.

- **Lead Event** — choose **New lead received**.
- **Lead Source** — choose **Any lead source**, **Facebook Lead Ads** or **IndiaMART**.

A lead with no phone number does not start the flow. If you have reached your contact limit, a new lead does not start the flow either. This trigger works on WhatsApp flows only.

### Flows started by a Reply Bot or ice breaker

On Messenger and Instagram, a flow can start from a [Reply Bot](/automation/reply-bots) or an [ice breaker](/core-setup/channels/ice-breakers). A Reply Bot answers comments on your posts. On Instagram it can also answer mentions and story replies. An ice breaker is a ready-made question that people can tap when they start a chat with you. *(Reply Bots need a paid plan. See [Free vs. paid](/getting-started/free-vs-paid).)*

To set this up, choose **Reply Bot** as the **Trigger Source**. Then:

- The flow never starts from an ordinary message. It runs only when a Reply Bot or an ice breaker starts it.
- The panel shows a **Started by** list with the Reply Bots that start this flow.
- If no bot uses the flow yet, you see: "No Reply Bot starts this flow yet. Create one in **Reply Bots** and choose “Start a flow”."

![The Start Trigger settings with Trigger Source set to Reply Bot. The panel explains that the flow runs only when a Reply Bot or an ice breaker starts it, lists one Reply Bot, Price list comments, under Started by, and shows a note that a comment Reply Bot sends the first message as one plain-text private reply](/automation/img/reply-bot-trigger.png)

**If a comment Reply Bot starts the flow.** The first message goes to the person as a private reply to their comment. Meta lets you send only one private message in reply to a comment. You can send more only after the person writes back. This is a Meta rule, not a WaMatrix.io one. Meta explains it for [Instagram](https://developers.facebook.com/documentation/instagram-platform/private-replies) and for [Messenger](https://developers.facebook.com/documentation/business-messaging/messenger-platform/discovery/private-replies).

WaMatrix.io sends this first message as plain text. When a comment Reply Bot uses the flow, the Start Trigger shows a reminder about this.

So the flow must follow two rules:

1. The flow can send only one message before the person replies. It must be a **Text Message** or an Ask step, such as **Ask Question**.
2. After a **Text Message**, add a **Wait for Reply** step before you send anything else. An Ask step already waits for the answer.

Steps that send nothing, such as **Delay**, **Condition** or **Assign Label**, can go anywhere.

If you break a rule, the Flow Builder marks the step in red and shows one of these messages. The words are the same on Messenger and Instagram:

> A comment trigger can only open with one plain-text message — Instagram allows one text reply per comment. Add a Wait for Reply (or ask a question) before this node.

> A comment trigger can only send one message before the person replies. Add a Wait for Reply before this node.

## Builder tools

The toolbar at the top right of the page has a few helpers:

- **Undo** and **Redo** — step back or forward through your changes.
- **Snap to grid** — keeps cards neatly aligned as you drag them.
- **Auto-arrange layout** — Automatically arranges the entire flow into a clean, left-to-right layout.
- **Save Flow** — saves your work. It's disabled while any card has an error.

## Steps on each platform

Each flow runs on one platform. Some steps work only on some platforms. The Flow Builder hides the steps that your flow's platform can't send. Steps that are not in this table work on all three platforms.

| Step | WhatsApp | Messenger | Instagram |
| --- | --- | --- | --- |
| [**WhatsApp Template**](/automation/flow-steps/basic#whatsapp-template) | Yes | No | No |
| [**Send Template**](/automation/flow-steps/basic#send-template) | No | Yes | Yes |
| [**WhatsApp Flow**](/automation/flow-steps/basic#whatsapp-flow) | Yes | No | No |
| [**Call To Action**](/automation/flow-steps/basic#call-to-action) | Yes | No | Yes |
| [**List Message**](/automation/flow-steps/interactive#list-message) | Yes | No | No |
| [**Location**](/automation/flow-steps/interactive#location) | Yes | Yes | No |
| [**Contact Card**](/automation/flow-steps/interactive#contact-card) | Yes | No | No |
| [**Reaction**](/automation/flow-steps/interactive#reaction) | Yes | No | No |
| [**Media Message**](/automation/flow-steps/interactive#media-message) | Yes | Yes | Yes, but no stickers |
| [**Ask Location**](/automation/flow-steps/ask#ask-location) | Yes | No | No |
| [**Sequence**](/automation/flow-steps/advanced#sequence) | Yes | Yes | No |
| [**WooCommerce Condition**](/automation/flow-steps/integrations#woocommerce-condition) | Yes | No | No |

**Send Template** sends one of your saved Messenger or Instagram templates. It used to be called **Messenger Template**.

### Limits on each platform

Each platform limits how long one text message can be:

- **WhatsApp:** 4,096 characters.
- **Messenger:** 2,000 characters.
- **Instagram:** up to 1,000 bytes (emojis use more). See [Instagram rules to know](/core-setup/channels/instagram#instagram-rules-to-know).

The WhatsApp and Instagram limits are Meta's rules, not WaMatrix.io's. Meta lists them for [WhatsApp text messages](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/text-messages) and [Instagram messages](https://developers.facebook.com/documentation/instagram-platform/instagram-api-with-instagram-login/messaging-api).

A [**Delay**](/automation/flow-steps/advanced#delay) step can wait up to 23 hours.
