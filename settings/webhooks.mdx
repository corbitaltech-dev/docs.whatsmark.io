When something happens on your WhatsApp number such as receiving a message, a template being approved, or a delivery update, WhatsMark.io receives the event and can forward a copy to your server, CRM, or automation tools like n8n or Zapier.

Find it under **Settings → Webhooks**.

## Turning it on

<Steps>
<Step title="Switch on Global Webhook Config">
  Use the switch at the top right of the card. The fields below unlock.
</Step>

<Step title="Enter your Webhook URL">
  The web address where events are sent, such as `https://your-server.com/webhook`.

  <Warning>
  The address has to be reachable from the internet. A local address such as `localhost`, `127.0.0.1` or an address inside your own network is refused when you save, for security reasons.
  </Warning>
</Step>

<Step title="Choose a Method">
  You can use POST or GET. POST is recommended. In both cases, the event data is sent as JSON in the request body.
</Step>

<Step title="Add a Signing Secret">
  Click the refresh icon to make one. It lets your server check that a request really came from us — see [Checking a request is really from us](#checking-a-request-is-really-from-us).

  <Note>
  The refresh icon only puts a new secret in the box. It is not in use until you save.
  </Note>
</Step>

<Step title="Pick your Events">
  Choose which events to forward to your server. There are 30 event types to choose from, including Messages, Message Echoes, Template Status Updates, and Phone Number Quality Updates. Only the events you select will be sent.
</Step>

<Step title="Save">
  Click **Save**.
</Step>
</Steps>

<Note>
Once forwarding is switched on, the Webhook URL and at least one event are required. You cannot save without them.
</Note>

## A different address for one channel

By default every channel sends to the same address. If you want one channel to go somewhere else, give it its own settings.

<Steps>
<Step title="Find the channel">
  Scroll to **Channel Overrides**. Only connected, active channels are listed.
</Step>

<Step title="Turn on Override">
  The channel's own fields open up.
</Step>

<Step title="Turn on Enable forwarding for this channel">
  Then fill in its own **Webhook URL**, **Method**, **Signing Secret** and **Events**. These are separate from the global ones.
</Step>

<Step title="Click Save Channel">
  That channel now sends to its own address. Every other channel carries on using the global settings.
</Step>
</Steps>

<Warning>
Turning **Override** back off removes that channel's settings. They are not kept for later — switch the override on again and you start with empty fields.
</Warning>
