When a customer sends you a photo, a voice note or a PDF on WhatsApp, the file itself stays on Meta's servers. WaMatrix.io only holds a link to it.

Meta deletes those files about **30 days** later. After that the link stops working, and the message in your chat shows nothing.

Turn this setting on and WaMatrix.io saves its own copy of every file as it arrives, so it is still there months later. Find it under **Settings → Inbound Media**.

## Turning it on

Switch on **Download inbound media**, then click **Save**.

From then on, every photo, video, voice note, document and sticker a customer sends is saved as it arrives.

Switch it off and new files stop being saved. Anything already saved stays as it is.

<Note>
This covers WhatsApp only. Files sent to you on Messenger are not saved.
</Note>

## Storage usage

Every saved file uses part of your plan's storage. You can check how much you have left on the [Dashboard](/reporting/dashboard-and-usage).

<Warning>
If your storage is full, new files are skipped without any warning. The message then keeps only Meta's link, which stops working after 30 days. If you receive a lot of files, check your storage regularly or upgrade your plan for more space.
</Warning>
