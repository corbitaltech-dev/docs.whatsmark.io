When a customer sends you a photo, a voice note or a PDF on WhatsApp, the file itself stays on Meta's servers. WaMatrix.io only holds a link to it.

Meta's link to those files expires about **30 days** later. After that, the chat shows your saved copy if you keep one. If you do not, the message shows **Attachment no longer available**.

Turn this setting on and WaMatrix.io saves its own copy of every file as it arrives. Your chat then shows that copy, so the file is still there months later. Find it under **Settings → Inbound Media**, on the **Core Platform** tab.

## Turning it on

Switch on **Download inbound media**, then click **Save changes**.

From then on, every photo, video, voice note, document and sticker a customer sends is saved as it arrives.

Switch it off and new files stop being saved. Anything already saved stays as it is.

<Note>
This covers WhatsApp only. Files sent to you on Messenger or Instagram are not saved.
</Note>

## Storage usage

Every saved file uses part of your plan's storage. You can check how much you have left on the [Dashboard](/reporting/dashboard-and-usage).

<Warning>
If your storage is full, new files are skipped without any warning. The message then keeps only Meta's link, which stops working after about 30 days. After that, it shows **Attachment no longer available**. If you receive a lot of files, check your storage regularly or upgrade your plan for more space.
</Warning>
